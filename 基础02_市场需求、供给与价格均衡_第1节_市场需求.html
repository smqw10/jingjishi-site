一、需求的含义与构成要素

1. 什么是需求 必考

需求是指在一定时间内和一定价格条件下，消费者对某种商品或服务愿意而且能够购买的数量。

需求的构成要素：购买的欲望 ＋ 支付能力，两者缺一不可。

愿意＋能够，缺一不可：

"愿意"是购买欲望，"能够"是支付能力。只有欲望没有钱（想买别墅但买不起）不构成需求——这只算"需要"或"欲望"，不是经济学意义上的需求；有钱但不想买也不构成需求；既愿意又买得起，才是需求。"需要"与"需求"一字之差，判断题拿"人人都想要"偷换成"人人都有需求"就是错的。考试就爱在这四个字上做文章——问"需求的构成要素"，答"购买意愿＋支付能力"。

🧠 愿能二字诀

"愿、能缺一不算数"——判断一句话是不是需求的定义/构成，就查"愿意"和"能够"两个字在不在场：只出现"愿意购买的数量"或只出现"能够购买的数量"都是残缺表述，选项里"愿意或者能够"更是错的。

2. 什么是市场需求

市场需求：在一定时间内、一定价格条件下和一定的市场上，所有的消费者对某种商品或服务愿意而且能够购买的数量。

一句话：市场需求是消费者需求的总和。相应地，需求曲线也有单个消费者的需求曲线和市场需求曲线之分，市场需求曲线是所有个别消费者需求曲线的水平加总。

例子　

一杯奶茶的"个人需求"是小王一个月愿意且买得起的那 8 杯；"市场需求"是把全城所有想喝且买得起的人的杯数加总起来的总量。"一定时间、一定价格、一定的市场"三个前提，一个都不能少。

二、影响需求的主要因素（7 个）

1. 七大因素总览 高频考点

因素 对需求的影响 白话记忆
①产品价格 影响需求的最重要的因素；价格与需求反方向变化 价高量低
②消费者偏好 偏好增强 → 需求增加 越喜欢越买
③消费者个人收入 收入增加 → 需求增加（反之亦然） 钱多买得多
④替代品价格 与本商品需求同方向变化 它贵我多买
⑤互补品价格 与本商品需求反方向变化 搭档贵我少买
⑥预期 预期涨价 → 提前买、现期需求增加；预期跌价 → 推迟买、现期需求下降 买涨不买跌
⑦其他 商品的品种、质量、广告宣传、地理位置、季节、国家政策等 杂项兜底
🧠 七因素口诀

"价偏收，替补预，杂项兜底"——自身价格（最重要）、偏好、收入，替代品、互补品、预期，再加品种质量广告等杂项。方向只记三条：自己价格反向（价高量低）、替代品价格同向、互补品价格反向。

2. 替代品 vs 互补品：一组必考对照 高频考点

对比项 替代品 互补品
定义 使用价值相近，可以相互替代来满足人们同一需要 使用价值上必须互相补充才能满足人们某种需要
常见例子 苹果与香蕉、牛肉与羊肉、火车与飞机、煤气和电、燃气热水器与电热水器 汽车和汽油、家用电器和电、牙刷与牙膏
该商品价格上升 → 本商品需求 增加（同方向） 减少（反方向）
一招分清替代与互补：

问一句"这两样东西能互相顶替吗"：各自都能单独满足需要、买谁看谁划算 → 替代品；必须搭配着用、拆开就不好使 → 互补品。燃气热水器和电热水器都能烧水洗澡，是替代；汽车和汽油拆开就没法用，是互补。

3. 计算题：相关商品价格变动的共同作用 高频考点

分步演算（替代品价格上升使甲商品需求量变动 500 千克，同期互补品价格上升使甲商品需求量变动 800 千克）：

  • 第一步：替代品价格上升 → 甲商品需求增加（替同）→ 记 ＋500 千克；
  • 第二步：互补品价格上升 → 甲商品需求减少（补反）→ 记 −800 千克；
  • 第三步：求代数和：＋500 − 800 ＝ −300，即甲商品需求量减少 300 千克。
例子　

健身房旁边奶茶店集体涨价（替代品涨）→ 来健身房买蛋白棒的人多了（＋500）；同期私教课涨价（互补品涨）→ 来健身的人少了，蛋白棒跟着少卖（−800）。两头一轧账：蛋白棒需求净减少 300 千克。

🧠 方向定符号，符号先于数字

"替涨记正、补涨记负，最后求代数和"。本章计算题最常见的错法不是算错数，而是没先定方向——把"减少 800"当成"+800"，得出"增加 1300"这种选项。先写符号再动笔。

三、需求函数、需求规律与需求曲线

1. 需求函数与需求规律

需求函数：假定价格之外的其他各因素不变，需求函数表明某商品的消费者随价格的变化愿意购买的数量。方程形式：Qd ＝ Qd(P)，如 Qd ＝ 60000 − 300×P（价格 P 越高，需求量 Qd 越小——式子里的负号正是"反向"的化身）。

需求规律：价格与需求之间呈反方向变化的关系——商品价格提高，消费者对它的购买量会减少；商品价格降低，购买量会增加。

2. 需求曲线与两种变动 高频考点 必考

需求曲线：反映需求量和价格的对应关系的曲线，向右下方倾斜。

需求的变化情形有两种：

对比项 需求数量变动 需求变动
原因 价格因素（商品自身价格） 非价格因素（收入、偏好、相关品价格、预期等）
图形表现 点的移动（沿既定需求曲线上下滑动） 线的移动（整条曲线位移/平移）

平移方向判别：消费者收入增加、偏好增强、替代品价格上涨、互补品价格下降等因素，导致需求曲线向右平移；反过来则向左平移。

例子　

奶茶店自己做活动降价（自身价格降）→ 老顾客沿着原来的需求曲线多买了几杯——曲线没动，是点移动；你这个月涨了工资（非价格因素）→ 同样的价格下奶茶从每周 2 杯变成 5 杯——整条需求曲线向右挪了窝，是线移动；隔壁茶饮店大促销（替代品降价）→ 同样的奶茶价格下你改喝茶去了，奶茶销量掉下来——奶茶自己的价格没变，动它的是替代品的价格 → 整条需求曲线向左平移。三个例子正好把"点移动、右移、左移"三种情形占全。

🧠 价动点动，非价线动

"自己价格走点，别的因素走线"——商品自身价格变化 → 沿着既定曲线做点移动；价格以外的任何因素变化 → 整条曲线平移。再背右移四件事："收入增、偏好强、替代品涨、互补品跌"→ 右移；反着来就左移。

💡 审题三步：谁变了 → 点还是线 → 左还是右

①题干只说"商品价格升降"→ 点移动，曲线不动；②题干出现收入、偏好、替代品、互补品、预期 → 线移动；③套"替同补反"定左右。特别警惕混场干扰项："生产成本下降"是供给的因素，无论怎么变都不移动需求曲线——真题最爱拿它设坑。

📌 本节速记卡
  • 需求＝一定时间、价格下愿意而且能够购买的数量；构成要素＝购买欲望＋支付能力，缺一不可
  • 市场需求＝所有消费者需求的总和；市场需求曲线＝个别消费者需求曲线水平加总
  • 影响需求 7 因素：产品价格（最重要、反向"价高量低"）、偏好（＋）、收入（＋）、替代品价格（＋）、互补品价格（−）、预期（买涨不买跌）、其他（品种质量广告地理季节政策）
  • 替同补反；相关品计算题：先定符号再求代数和（＋500−800＝−300）
  • Qd＝Qd(P)；需求规律＝价格与需求反方向变化
  • 需求曲线向右下方倾斜；点移动＝自身价格、线移动＝非价格因素；右移四件事＝收入增、偏好强、替代品涨、互补品跌
讲义·多选
根据需求的基本含义，需求的构成要素包括（　）。
查看答案与解析
✅ 参考答案：CD

析：需求＝消费者愿意而且能够购买的数量——"愿意"对应购买意愿（C），"能够"对应支付能力（D），两个构成要素缺一不可。税收政策（A）、市场预期（E）属于影响需求的因素，不是构成要素；生产者供应数量（B）是供给侧概念，与需求的构成无关。 :::

2025·单选
下列各组商品中，互为替代品的是（　）。
查看答案与解析
✅ 参考答案：A

析：替代品＝使用价值相近、可以相互替代满足同一需要的商品——燃气热水器和电热水器都能烧水沐浴，可互相顶替（A 对）。汽车和汽油、家用电器和电、牙刷与牙膏都必须搭配使用，属互补品（B、C、D）。判断就一句：能不能互相顶替。 :::

讲义·单选

查看答案与解析
✅ 参考答案：C

析：分步演算——替代品价格上升 → 甲需求增加（替同），记＋500；互补品价格上升 → 甲需求减少（补反），记−800；代数和 ＋500−800＝−300，即减少 300 千克（C 对）。B 把两个变动同号相加（500＋800＝1300），是没先定方向的典型错误；D 则是方向全反——方向题先定符号再算数。 :::

✅ 参考答案：ABC

析：影响需求的因素＝产品价格、消费者偏好、消费者收入、替代品价格（A）、互补品价格（C）、预期（B），以及品种、质量、广告宣传、地理位置、季节、国家政策等其他因素。产业结构（D）、生产成本（E）是影响供给的因素——见到"成本、产业"就归供给篮子，别放需求里。 :::

讲义·多选
通常情况下，在坐标图上，引起小汽车的需求曲线向左平移的原因是（　）。
查看答案与解析
✅ 参考答案：A

析：汽油是小汽车的互补品，油价上涨 → 用车成本高 → 买车需求减少 → 需求曲线左移（补反，A 对）。公共交通是小汽车的替代品，票价上涨 → 更多人改开私家车 → 需求曲线右移（B 方向反了）；收入增加 → 需求增加 → 右移（D 反）；生产成本是供给侧因素（C），根本不移动需求曲线，属混场干扰项。 :::

题库·单选
在横轴表示需求量、纵轴表示价格的坐标平面上，假定其他条件不变，消费者预期某种商品价格将要上升，会导致该商品的需求曲线（　）。
查看答案与解析
✅ 参考答案：C

析：预期是价格以外的因素 → 线移动，先排除 A、B（那是自身价格变动引起的沿曲线点移动）。预期未来涨价 → 消费者提前购买 → 现期需求增加 → 曲线右移（C 对，D 方向反了）。口诀"买涨不买跌"。 :::
