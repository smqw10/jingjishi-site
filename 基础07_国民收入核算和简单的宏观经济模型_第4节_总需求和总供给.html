一、总需求

1. 总需求的含义 高频考点

定义：在其他条件不变的情况下，在某一给定的价格水平上，一个国家或地区各种经济主体愿意购买的产品总量。

"愿意购买"是关键词：

总需求不是"实际买了多少"，而是"在这个价格水平上愿意买"的总量——它天生是和价格水平配对的概念：价格一变，愿意买的量就跟着变。

例子　

西红柿 3 元一斤时你愿意买 2 斤，涨到 8 元只愿买半斤——"每个价格对应的愿意购买量"连成一条线，放到整个经济体的所有产品上，就是总需求。

2. 总需求的影响因素 高频考点必考★★★

方向 因素 传导
反方向 价格总水平 价格总水平下降 → 总需求上升（反之亦然）
↑ 利率 利率下降 → 企业投资和居民购买住宅及耐用消费品的数量增加 → 总需求增加
↑ 税收 税收减少 → 企业和居民的收入增加 → 总需求增加
同方向 货币供给量 货币供给量增加 → 总需求增加
↑ 政府购买 政府购买增加 → 总需求增加
↑ 预期 企业预期利润增长 → 扩大投资；居民预期未来收入增长 → 增加消费
方向对照一句话：

"价利税，反着走；币购期，顺着流"——价格总水平、利率、税收与总需求反方向；货币供给量、政府购买、预期与总需求同方向。六个因素三反三同，各占一半，先归类再选。

例子　

房贷利率从 5% 降到 3.5%：月供变少，原本观望的家庭下单买房，企业也敢贷款扩产 → 总需求增加——"利率下降、总需求上升"，这就是反方向的日常版。反过来看政府购买：政府多修一条路，总需求就多一块，同方向。

🧠 总需求方向口诀

"价利税反，币购期同"——见到因素先归类：价格总水平、利率、税收 → 反向；货币供给量、政府购买、预期 → 同向。

💡 清单之外皆干扰

教材列的影响总需求的因素就是这六个。财政转移支付不在清单里——见"不属于影响总需求的因素"要会挑它；而"消费税"属于税收范畴，在清单内。做题先默写"价利税、币购期"六个字，再对选项，不凭感觉。

3. 总需求曲线 高频考点

在宏观经济学中，为了说明价格总水平的变化，假定其他因素不变，只分析价格总水平与总需求的关系，就形成了总需求曲线 AD。总需求曲线向右下方倾斜；横坐标 Y 为总产出，纵坐标 P 为价格总水平。

点动还是线动：

价格总水平变动 → 沿着 AD 曲线上下滑动（点移动）；其他因素（利率、税收、货币供给量等）变动 → 整条 AD 曲线平移（线移动）。AD 曲线只画"价格总水平—总需求"这一对关系，别把"利率与总需求"之类的也当成 AD 曲线。

例子　

油价等整体物价上涨（价格总水平上升）→ 全社会愿意购买的总量减少，沿着 AD 曲线向左上方滑动；央行降息（其他因素变了）→ 同样的价格水平下大家更愿意买，整条 AD 曲线向右平移。

4. 价格总水平变动的三大效应 高频考点必考★★★

效应 传导渠道 与总需求的关系
财富效应 价格总水平变动 → 居民收入及财富的实际购买力反方向变动 → 总需求变动 反方向
利率效应 价格总水平变动 → 利率变化 → 进而与投资、消费及总需求反方向变化 反方向
出口效应 价格总水平变动 → 汇率变动 → 影响出口需求变化 → 与总需求反方向变化 反方向
三条路一个方向：

价格涨 → 手里的钱购买力缩水（财富）、借钱成本抬升（利率）、本国货变贵出口受阻（出口）→ 三条路都通向"总需求减少"。方向全部反，差别只在中介渠道：购买力、利率、汇率。

例子　

物价普遍上涨：存款的实际购买力缩水，老百姓捂紧钱包（财富效应）；资金紧张、利率走高，企业削减投资（利率效应）；本国商品卖到国外变贵，出口订单下滑（出口效应）——三条渠道同时给总需求"降温"。

🧠 三效应口诀

"财看购买力，利看借钱贵，出看汇率贵，三路全反向"——见"汇率→出口需求"选出口效应；见"实际购买力"选财富效应；见"引起利率变化"选利率效应。

二、总供给

1. 总供给的含义与影响因素 高频考点必考★★★

定义：在其他条件不变的情况下，一定时期内在一定价格水平上，一个国家或地区的生产者愿意向市场提供的产品总量。

总供给的变动主要取决于企业利润水平，而利润水平又取决于市场价格和生产成本——因此，决定总供给的基本因素是价格和成本。

层次 因素 说明
基本因素 价格、成本 直接决定利润水平 → 决定总供给
其他因素 技术进步、工资水平变动、能源及原材料价格变动等 都是通过对成本的影响影响企业利润水平，从而影响总供给
重要影响因素 预期 企业对未来利润的预期下降 → 减少生产 → 总供给减少
一切为了利润：

总供给的逻辑链只有一条：利润＝价格−成本。技术、工资、能源原材料这些"其他因素"都是借成本的道来影响利润的；预期则是提前按下生产暂停键的"心理因素"。题目问"基本因素"，只认价格和成本两个。

例子　

铜价大涨，电缆厂成本飙升、利润变薄 → 减产（成本影响总供给）；电缆售价同步上调、利润恢复 → 又愿意多产（价格影响总供给）；若老板预期明年行情更差 → 现在就压缩生产（预期影响总供给）。

🧠 总供给因素口诀

"价本定供给，其余借道成本"——基本因素只有价格和成本；技术、工资、能源原材料都通过成本起作用；预期是重要影响因素。

2. 总供给曲线：长短期两副面孔 高频考点必考★★★

曲线 形状 原因
长期总供给曲线 垂直于横轴的直线 从长期看，总供给变动与价格总水平无关；长期总供给只取决于劳动、资本与技术，以及经济体制等因素
短期总供给曲线 向右上方倾斜 短期内价格变动会影响生产者愿意提供的数量
长期"不看价格"：

长期总供给是经济的"产能天花板"，由劳动、资本、技术、经济体制这些硬实力决定——价格再怎么涨，天花板不跟着涨。短期则不同，价格信号能左右企业愿意生产的量，所以短期曲线随价格向上走。

例子　

长期总供给像"楼层天花板"：不管今天物价高低，楼就盖这么高（劳动、资本、技术决定）；短期总供给像"上楼的楼梯"：价格越往上走，企业越愿意多生产（向右上方倾斜）。

🧠 总供给曲线口诀

"长期一根筋（垂直横轴），短期向上爬（右上倾斜）"——长期只认劳动、资本、技术与经济体制；短期才搭价格的车。

3. 总供求模型：需求拉动型通货膨胀的基本模型 高频考点

  • 长期：总供给曲线是一条垂直于横轴的直线 → 影响价格总水平的是总需求；
  • 短期：假定总供给曲线不变，总需求的增长使总需求曲线向右平行移动 → 价格总水平上涨——这就是需求拉动型通货膨胀的基本模型。
两个"谁说了算"：

长期：总供给定产量、总需求定价格；短期：总需求一膨胀，价格就上涨（需求拉动通胀）。模型里 AD 右移是"元凶"，短期总供给曲线是背景板。

例子　

经济过热、信贷宽松，总需求猛增 → AD 曲线向右平移，短期供给跟不上 → 物价普遍上涨。"钱追货、货涨价"，就是需求拉动型通货膨胀的基本模型。

🧠 总供求模型口诀

"长期价格看需求，短期需求拉通胀"——长期垂直供给下价格由总需求决定；短期 AD 右移推高价格总水平＝需求拉动型通胀的基本模型。

💡 曲线方向总复习（方向对照类必看）
  • 总需求曲线：向右下方倾斜（价格↑ → 总需求↓）；
  • 短期总供给曲线：向右上方倾斜；
  • 长期总供给曲线：垂直于横轴（与价格总水平无关）——"长期总供给曲线向右上方倾斜""总供给曲线向右下方倾斜"都是错的；
  • 总需求增长慢于总供给增长不会推高价格——"总需求增长使 AD 右移、价格上涨"的前提是短期供给曲线不变。 做题先把三条曲线的形状默出来再对选项，方向题"觉得对"不算数。
📌 本节速记卡
  • 总需求：其他条件不变、给定价格水平上各种经济主体愿意购买的产品总量
  • 六因素方向："价利税反，币购期同"（价格总水平/利率/税收反向；货币供给量/政府购买/预期同向）
  • AD 曲线：只分析价格总水平与总需求，向右下方倾斜；横轴 Y 总产出、纵轴 P 价格总水平
  • 三效应：财富（购买力）、利率（利率）、出口（汇率）——与总需求全反方向
  • 总供给：一定时期、一定价格水平上生产者愿意提供的产品总量；基本因素=价格和成本；技术/工资/能源借道成本；预期重要
  • 总供给曲线：长期垂直横轴（只取决于劳动、资本、技术、经济体制）；短期向右上方倾斜
  • 总供求模型：长期影响价格总水平的是总需求；短期 AD 右移→价格上涨＝需求拉动型通胀的基本模型
