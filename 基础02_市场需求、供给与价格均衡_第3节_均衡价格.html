一、均衡价格的形成

1. 均衡价格与均衡数量 必考

需求曲线与供给曲线相交于 E 点。在 E 点，供给量和需求量相等，其数量为 Q0，通常被称为均衡数量（均衡产量）；此时的市场价格为 P0，通常被称为均衡价格。

均衡价格就是市场供给力量和需求力量相互抵消时所达到的价格水平。

均衡价格的形成：供求拔河
D 向右下：价高买得少；S 向右上：价高卖得多
供过于求 → 价格下降；供不应求 → 价格上升。两股力量在 E 点相互抵消，形成均衡价格 P0 与均衡数量 Q0——均衡是动态调整的结果，偶然、暂时、相对。

均衡价格的特点：实际生活中供求十分活跃、经常变化，所以任何市场上供求平衡都是偶然的、暂时的、相对的。

拔河拔平了：

把市场想成一场拔河：买方使劲压价，卖方使劲抬价，两股力量正好"相互抵消"的那一点就是均衡价格。两边的力量天天在变，所以平衡永远是偶然的、暂时的、相对的——均衡是动态调整的结果，不是一劳永逸的状态。

需求变动 → 均衡点怎么走
场景：收入增加（正常品）→ 需求增加，需求线 D0 右移到 D1
需求增加 → D 右移 → 价格 P0→P1（↑）、数量 Q0→Q1（↑）：需求与均衡价格、均衡数量同方向变动。需求减少则 D 左移，P↓Q↓ 同理。

2. 价格的基础：商品价值 高频考点

均衡价格能够说明市场价格与市场供给、市场需求之间的关系，但并不能说明价格的决定：

  • 商品价格的高低首先取决于其价值量的大小；
  • 商品价值是决定商品价格的基础；
  • 商品价格总是在市场供给和市场需求关系的影响下围绕价值上下波动。
例子　

早市白菜开价 3 元没人买（供大于求），摊主降到 2 元很快卖空（供不应求），下午回升到 2.5 元——价格一天之内随供求上蹿下跳（供求造浪），但始终离不开"种一棵白菜所耗费的劳动"这个大致水平（价值是锚）。

🧠 价值是锚，供求造浪

"价值是锚，供求造浪"——价格随供求围绕价值上下波动，锚（价值）决定它大致停在哪。考试问"决定和影响商品价格的基础"，答案只有一个：商品价值——选市场供求或均衡价格都错，均衡价格本身就是供求抵消的结果。

二、均衡价格模型的运用：最高限价与保护价格 ★★★ 高频考点

1. 两价格对照表

对比项 最高限价 保护价格（支持价格、最低限价）
规定 政府为某种产品规定一个具体价格，市场交易只能在这一价格之下进行 政府为某种产品规定一个具体价格，市场交易只能在这一价格之上进行
与均衡价格的关系 低于均衡价格 高于均衡价格
目的 保护消费者利益或降低某些生产者的生产成本 保护生产者利益或支持某一产业发展
应用场景 给市场交易价格"封顶" 我国和世界上一些国家或地区用它支持农业生产、稳定农民收入水平
后果 价格便宜 → 刺激消费、限制生产 → 需求量超过供给量 → 市场供给短缺 价格贵 → 刺激生产、抑制消费 → 供给量超过需求量 → 市场供给过剩
典型现象 排队抢购；短缺之下可能出现黑市 过剩若无政府收购兜底，可能出现以低于保护价格私下成交的黑市
最高限价 vs 保护价格
同一个均衡：管制线画在哪一侧，后果就落在哪一侧
最高限价（＜P0）：价低 → 刺激消费、限制生产 → 短缺——排队抢购、黑市。通常只作应急手段。
保护价格（＞P0）：价高 → 刺激生产、抑制消费 → 过剩——政府须收购兜底，多用于支持农业。

2. 分步推演：限价后果怎么推

以最高限价为例，四步推出"短缺"： ①限价低于均衡价格 → ②市场交易价便宜 → ③买的人多（需求量上升）、卖的人少（供给量下降）→ ④需求量＞供给量 → 短缺、排队抢购。 保护价格完全对称：高于均衡 → 贵 → 买得少、卖得多 → 过剩。

🧠 限高必低，保低必高

"限高必低，保低必高"——名字里带高的（最高限价）必低于均衡价格；保护价格（又称最低限价）必高于均衡价格。再接下半句："限价短缺，保护过剩"。方向题、后果题，全靠这十二个字打底。

例子　

有的城市给房租"封顶"（最高限价）→ 房东觉得不划算、出租房变少，租客排队抢房源 → 住房"短缺"；国家对稻谷定最低收购价（保护价格）→ 农民种粮划算、粮食多到卖不完 → "过剩"，由政府收购兜底。一个管"别太贵"，一个管"别太贱"。

💡 方向一错全错：先定"低于还是高于"，再分清配套措施

第一步圈出题干的"最高限价/保护价格"六个字 → 口诀定下与均衡价格的高低关系 → 再顺推后果（低于均衡 → 短缺；高于均衡 → 过剩）。配套措施别串门：配给制是最高限价（短缺时分配有限商品）的配套措施，不是保护价格的；保护价格面对的是过剩，靠政府收购。多选题里"配给制是保护价格的配套措施"必错。

📌 本节速记卡
  • 均衡价格＝市场供给力量和需求力量相互抵消时的价格水平；交点 E 上供给量＝需求量＝均衡数量 Q0
  • 供求平衡是偶然的、暂时的、相对的；均衡价格不能说明价格的决定
  • 商品价值是决定商品价格的基础，价格在供求影响下围绕价值上下波动
  • 最高限价：低于均衡价格、保护消费者、后果＝短缺（排队抢购、黑市）、配套＝配给制
  • 保护价格（支持价格/最低限价）：高于均衡价格、保护生产者/支持农业稳收、后果＝过剩（政府收购）
  • 口诀：限高必低，保低必高；限价短缺，保护过剩
2025·单选
在市场经济中，决定和影响商品价格的基础是（　）。
查看答案与解析
✅ 参考答案：D

商品价值是决定商品价格的基础（D 对），价格总是在市场供给和市场需求关系的影响下围绕价值上下波动。市场需求（A）、市场供给（B）只是让价格波动的力量；均衡价格（C）本身就是供求抵消的结果，都谈不上"基础"。 :::

2025·多选
政府采用最高限价措施时，可能出现的情形有（　）。
查看答案与解析
✅ 参考答案：BDE

"限高必低"——最高限价低于均衡价格（B 对）→ 价格便宜 → 刺激消费、限制生产 → 需求量高于均衡数量（A 说低于，反了）、供给量低于均衡数量（C 说高于，反了）→ 供不应求 → 市场供给短缺（E 对），现实表现就是排队抢购（D 对）。 :::

讲义·多选
下列关于保护价格的说法中，错误的有（　）。
查看答案与解析
✅ 参考答案：CDE

本题找错误项。A、B 是保护价格的标准表述（保护生产者利益、支持农业生产和农民收入），不选。C 错——配给制是最高限价（短缺）的配套措施，保护价格面对的是过剩；D 错——保护价格高于均衡价格，贵了会抑制消费而不是刺激消费；E 错——"保低必高"，保护价格一般高于均衡价格。 :::

题库·多选
政府采用保护价格措施时，可能出现的情况有（　）。
查看答案与解析
✅ 参考答案：BDE

保护价格高于均衡价格（C 说低于，错）→ 刺激生产、抑制消费 → 生产量增加（A 错）、供给量超过需求量 → 市场需求量低于均衡数量（D 对）、市场供给过剩（B 对）；过剩产品若无政府收购兜底，市场上还可能出现黑市交易（E 对）。 :::

题库·单选
关于保护价格的说法正确的是（　）。
查看答案与解析
✅ 参考答案：B

保护价格高于均衡价格（C 反）→ 刺激生产、抑制消费（A 错在"刺激消费"）→ 供给量超过需求量 → 可能导致市场供给过剩（B 对）。配给制是最高限价的配套措施（D 错），别让它串门。 :::

题库·单选
均衡数量的内涵是（　）。
查看答案与解析
✅ 参考答案：C

均衡数量＝供求曲线交点 E 上，供给量和需求量相等时的数量，也称均衡产量（C 对）。A 错——均衡要求供求数量正好相等，不是随便有交易就算；B 是无中生有的编造关联；D 错——供给或需求任何一方变动都会使交点移动，均衡数量随之改变。 :::
