一、绩效反馈面谈

1. 面谈的目的与作用（★★）

类别 内容
目的（4 条） ①向员工反馈绩效考核结果；②向员工传递组织远景目标；③弄清绩效不合格原因；④为下一绩效周期工作的展开做好准备
作用（3 条） ①提供沟通平台，使考核公开化；②使员工了解不足，有利于改善绩效；③通过沟通，消除组织目标与个人目标之间的冲突
🧠 上岸熊口诀：反目分备

"反、目、分、备"——反馈考核结果、传递远目标（远景目标）、分析不合格原因、准备下一绩效周期。四条背死，多选、单选（"不包括"题型）都能秒。

例子　

年底经理约小周面谈：先告诉他考核得分和依据（反馈结果），再聊聊公司明年要打的仗（传递远景），一起弄清"为什么下半年掉了链子"（弄清原因），最后定下明年第一季度的小目标（准备下一周期）——面谈就齐活了。

2. 面谈的注意事项（★）

  1. 主管人员应当采取赞扬与建设性批评相结合的方式，避免员工产生抵触情绪；
  2. 把重点放在解决问题上——关注未来而不是过去，反馈面谈的最终目的是改进绩效；
  3. 鼓励员工积极参与到反馈过程中。
一句话定调：

面谈不是"批斗会"：夸与批结合、向前看（解决问题）而非翻旧账、让员工多开口。最终目的只有一个——改进绩效。

3. 面谈中主管人员的误区（★）

误区 表现 对策提示
不适当发问 诱导发问、发问内容无逻辑性 避免一次问两件事、问题要有逻辑
理解不足 没有真正听懂对方的观点 将对方谈话归纳、回馈，确保理解
期待预期结果 在无意识中曲解员工的观点 放下预设答案
自我中心和感情化的态度 会失去面谈的客观性和公正性 对事不对人
以对方为中心及同情的态度 过度关怀会使对方产生厌烦情绪 关怀有度
🧠 五误区口诀

"问、解、期，自、同情"——不适当发问、理解不足、期待预期结果；自我中心感情化、以对方为中心同情。注意最后一个："过度同情"本身也是误区。

例子　

小赵倾诉完，主管直接说"所以你是不想干了？"（诱导式不适当发问）；聪明的做法是把小赵的话复述一遍："你的意思是排班太紧导致出错多，对吗？"（归纳回馈，破解理解不足）。

4. 绩效面谈的技巧（★）

  1. 时间场所的选择：避免上下班、开会等让人分心的时段；选择安静、轻松的会客厅；
  2. 建立彼此信任，开诚布公、坦诚沟通；
  3. 主管人员认真倾听；鼓励员工多说话；
  4. 以积极的方式结束对话（该结束时立即结束）。
🧠 上岸熊提示：积极、合适

"积极、合适"——结束方式要积极（令人振奋地收尾），时间场所要合适（避开上下班开会、选安静轻松处）；再加"多听少打断"。

💡 2018 真题排雷

"重点放在批评教育"（错，重在解决问题）、"随时打断员工陈述"（错，应认真倾听、鼓励多说话）、"在食堂吃午餐时面谈"（错，场所应安静轻松）——三个错误说法对应三条技巧的反面。

二、绩效改进

1. 绩效改进的概念与程序（★）

概念：通过找出组织或员工工作绩效中的差距，制订并实施有针对性的改进计划来提高员工绩效水平的过程。

程序（5 步）：①绩效诊断与分析（绩效改进过程的第一步）；②组建绩效改进部门；③选择绩效改进方法；④绩效改进实施管理；⑤绩效改进效果评价。

2. 四种绩效改进方法（★★★）

方法 关注点
卓越绩效标准 关注组织管理理念——描述卓越企业的管理信念和行为，改进组织整体效率和能力
六西格玛管理 关注组织业务流程的误差率——通过减少企业业务流程中的偏差（减少失误率、控制错误和废品增加），提升组织绩效
ISO 质量管理体系 关注组织产品（服务）的生产过程——在企业内部制定、实施和改进质量管理体系，使产品或服务水平提升，增强客户满意度
标杆超越 关注点灵活多变——可以把优秀企业的某个管理"片断"作为标杆，也可以把优秀企业整体作为标杆
🧠 上岸熊提示：六西格玛的关键词

六西格玛管理的关键词是失误率、错误率、误差率、差错率、废品率、偏差等，但不能是正确率、准确率、合理性等——考题问"通过减少业务流程中的偏差提升绩效"，选六西格玛；选项里出现"提高正确率"式的说法就掉坑了。

🧠 四方法口诀

"卓越管理念，六西格玛纠偏差，ISO 抓生产过程，标杆灵活变"——四个方法各抱一个关注点，先看题干关键词再对号。

例子　

工厂半年废品率超标，引入六西格玛项目专门压偏差、降废品率（六西格玛管理）；食堂后厨按 ISO 流程改造，饭菜质量稳定了顾客更满意（ISO 质量管理体系）；小公司整体对标行业龙头学管理信念（卓越绩效标准），也可以只学人家一个班组的交接班制度（标杆超越）。

3. 绩效改进效果评价（★★）

从四个方面进行：①反馈——客户、员工、供应商对改进结果的反馈；②能力——改进实施后员工能力素质的提升程度；③转变——改进活动对工作方式的影响；④结果——改进所形成的结果与预期的对比。

🧠 效果评价四字诀

"反、能、转、结"——反馈、能力、转变、结果，顺序固定，多选直接对号。

三、绩效考核结果的分析与应用

1. 绩效考核结果的分析：四种员工类型（★★★）

根据员工的工作态度和工作能力两个维度，把组织中的员工划分为四种类型：

类型 工作态度 工作能力 应对措施
贡献型 好 高 组织要给予必要的奖励
安分型 好 不足 组织要进行必要的培训以提升其工作技能
堕落型 差 低 进行适当的惩罚、敦促其改进绩效
冲锋型 差 高 主管人员应当对其进行绩效辅导
🧠 上岸熊口诀：公安罗峰

"公（贡献型）、安（安分型）、罗（堕落型）、峰（冲锋型）"——四类型先记名字，再记对策一句话：贡献奖、安分训、堕落罚、冲锋辅。

例子　

小组四个人：老陈态度好能力强，年终发大奖（贡献型）；小吴踏实肯干但方法不对，送去培训（安分型）；小马又懒又不行的，谈话警告（堕落型）；小孙能力拔尖却自由散漫，主管多辅导多沟通，把心拢住（冲锋型）。

2. 绩效考核结果的应用（★）

  1. 应用于衡量招聘结果；
  2. 为人员调配提供依据；
  3. 为奖金分配提供依据；
  4. 用于员工的培训与开发；
  5. 应用于员工职业生涯规划。
🧠 应用五条口诀

"招、调、奖、培、职"——衡量招聘、人员调配、奖金分配、培训开发、职业生涯规划。

📌 本节速记卡
  • 面谈目的："反目分备"——反馈结果、传递远景目标、弄清不合格原因、准备下一周期
  • 面谈作用：沟通平台考核公开化、了解不足改善绩效、消除组织与个人目标冲突
  • 注意事项：赞扬＋建设性批评结合；重点解决问题（关注未来，最终目的是改进绩效）；鼓励员工参与
  • 主管五误区：不适当发问、理解不足（对策＝归纳回馈）、期待预期结果、自我中心感情化、以对方为中心同情（过度关怀招厌烦）
  • 面谈技巧：时间场所合适（避开上下班开会、安静轻松）、建立信任坦诚沟通、认真倾听鼓励多说话、以积极方式结束
  • 绩效改进：第一步＝绩效诊断与分析；四方法＝卓越绩效标准（管理理念）、六西格玛（减少流程偏差）、ISO（生产过程、客户满意度）、标杆超越（灵活多变）；效果评价＝反、能、转、结
  • 四种员工（态度×能力）：贡献型奖励、安分型培训、堕落型惩罚、冲锋型绩效辅导（公安罗峰）
  • 结果应用：招、调、奖、培、职

✅ 参考答案：D

析：面谈技巧的落脚点之一就是以积极的方式结束对话，该结束时立即结束，D 正确。A 错误——重点应放在解决问题上，关注未来而不是过去；B 错误——应认真倾听、鼓励员工多说话，不能随意打断；C 错误——面谈应选择安静、轻松的场所，食堂嘈杂且不私密。 :::

题库·单选
为了避免走入绩效面谈中的"理解不足"误区，管理者应采取的行为是（　）。
查看答案与解析
✅ 参考答案：A

析：破解"理解不足"的办法是把对方的谈话加以归纳、回馈，确保对问题的真正理解，A 正确。B 针对的是"不适当发问"；C 属于面谈的一般技巧，与理解不足无直接对应；D 本身就是"以对方为中心及同情的态度"误区——过度关怀会使对方产生厌烦情绪。 :::

2019·单选
通过减少企业业务流程中的偏差，提升组织绩效水平的绩效改进方法是（　）。
查看答案与解析
✅ 参考答案：C

析：六西格玛管理关注组织业务流程的误差率，通过减少企业业务流程中的偏差（减少失误率、控制错误和废品增加）使组织绩效提升到更高水平。卓越绩效标准关注管理理念；标杆超越关注对标最佳实践；ISO 质量管理体系关注产品（服务）的生产过程。记住"偏差/误差率"三个字，此题零思考。 :::

2018·多选
企业可以根据绩效考核结果划分出四种类型的员工，关于针对这四种员工应当采取的措施的说法，正确的有（　）。
查看答案与解析
✅ 参考答案：ABCD

析：按"工作态度×工作能力"分四类——贡献型（态度好能力强）给予必要的奖励（B 对）；安分型（态度好能力不足）进行必要的培训提升技能（D 对）；堕落型（态度差能力低）适当的惩罚、敦促改进绩效（A 对）；冲锋型（态度差能力强）进行绩效辅导（C 对）。E 的"防守型"是编造的类型，四类型就是"公安罗峰"。 :::
