📈 曲线与图形速记

全部曲线图集中总复习：先看形状，再记要点。每张图后接"考点框"，考前只过要点即可。
供求与价格（第1–2章）消费者与生产者理论（第2–3章）市场结构与要素（第4–5章）宏观经济（第6–9章）市场失灵与财政（第6、13章）统计（第23–27章）人力资源（第2–3章）

📈 供求与价格（第1–2章）

均衡价格的形成

均衡价格的形成：供求拔河
D 向右下：价高买得少；S 向右上：价高卖得多
供过于求 → 价格下降；供不应求 → 价格上升。两股力量在 E 点相互抵消，形成均衡价格 P0 与均衡数量 Q0——均衡是动态调整的结果，偶然、暂时、相对。
均衡价格：
  • 均衡价格 = 需求曲线与供给曲线交点对应的价格，此时需求量 = 供给量
  • 供大于求 → 价格下跌；供小于求 → 价格上涨，都会自动回到均衡

供求变动（比较静态）

需求变动 → 均衡点怎么走
场景：收入增加（正常品）→ 需求增加，需求线 D0 右移到 D1
需求增加 → D 右移 → 价格 P0→P1（↑）、数量 Q0→Q1（↑）：需求与均衡价格、均衡数量同方向变动。需求减少则 D 左移，P↓Q↓ 同理。
曲线怎么动：
  • 自己价格变化 → 沿着曲线"点移动"；其他因素变化 → 整条曲线"线移动"
  • 需求右移四件事：收入增、偏好强、替代品涨、互补品跌
  • 供给：成本降、技术进 → 右移；成本升 → 左移
  • 需求增 + 供给不变 → 均衡价格、数量同升；供给增 + 需求不变 → 价格降、数量升

最高限价与保护价格

最高限价 vs 保护价格
同一个均衡：管制线画在哪一侧，后果就落在哪一侧
最高限价（＜P0）：价低 → 刺激消费、限制生产 → 短缺——排队抢购、黑市。通常只作应急手段。
保护价格（＞P0）：价高 → 刺激生产、抑制消费 → 过剩——政府须收购兜底，多用于支持农业。
🧠 限高必低，保低必高

名字带"高"的（最高限价）必低于均衡价格 → 短缺（排队、黑市）；保护价格（最低限价）必高于均衡价格 → 过剩（政府收购）。

📈 消费者与生产者理论（第2–3章）

无差异曲线与预算线（无图，记特征）

无差异曲线三特征：
  1. 任一点效用相同；负斜率、凸向原点（边际替代率递减）
  2. 任意两条不相交
  3. 离原点越远，效用水平越高
预算线怎么动：
  • 收入变动 → 整条平移（收入增 → 右移）
  • 某一种商品价格变动 → 预算线绕点旋转
  • 消费者均衡：无差异曲线与预算线相切，切点处 MRS = 价格之比 P₁/P₂

短期成本曲线

短期成本曲线族：一条 U 形线穿过两条 U 形线
上升的 MC 先后穿过 AVC、ATC 的最低点——交前边小、交后边大
触底顺序：MC 最早 → 其次 AVC（M′）→ 最后 ATC（M）；M′、M 是两条平均线由降转升的转折点。ATC−AVC 的垂直距离＝AFC，随产量增大而缩小，两线永不相交；AFC 一路递减趋近横轴。
🧠 边际穿过平均的最低点

MC 交 AVC、AC 于其最低点；交点之前 MC < 平均（拉低平均），之后 MC > 平均（拉高平均）；三条 U 形线里 MC 最先触底。类比：新同学成绩（边际）拉高/拉低班级平均分。

短期产量曲线（TP、AP、MP）

产量曲线：三条线、三个临界点
TP 的斜率由 MP 决定：MP 递增段 TP 凸向 L 轴，MP 递减段 TP 凹向 L 轴
L1：MP 最高（TP 拐点）→ L2：MP＝AP，AP 最高 → L3：MP＝0，TP 最大；超过 L3 后 MP 为负、TP 递减。口诀：边大均增、边小均减、相等最高。
产量三线：
  • MP 与 AP 交于 AP 最高点；MP = 0 时 TP 最大
  • 边际产量递减发生在 MP 曲线开始下降之后（边际报酬递减规律）

📈 市场结构与要素（第4–5章）

完全竞争市场

完全竞争：行业定价，企业接受
左：整个行业的供求交点定出均衡价格 P0；右：个别企业按 P0 面对一条水平需求线
个别企业的需求曲线＝平均收益线＝边际收益线（三线合一的水平线），与行业需求曲线不是同一条线。总收益 TR＝P×Q 随销量上升，是条上升的线、不是水平线。
完全竞争：
  • 厂商需求曲线是水平线：AR = MR = P（价格接受者）
  • 短期均衡条件 MR = MC；长期均衡时利润为零

完全垄断市场

完全垄断：两线重合、边下更陡
需求曲线＝行业需求曲线；平均收益线与之重合，边际收益线在其下方且更陡峭
需求曲线＝AR（两线重合），MR 在 AR 下方且更陡（多卖就要降价，MR＜AR）。注意对比：三线合一（需＝均＝边）只属于完全竞争，完全垄断必错。
完全垄断：
  • 需求曲线向右下方倾斜，MR < AR（MR 线在下方、斜率更陡）
  • 可实行价格歧视：一级（完全）、二级（按购买量）、三级（按人群/市场分割）

劳动力供给曲线（向后弯曲）

个人劳动供给曲线：向后弯曲
两股力量同时存在，强弱随贫富变化：穷时替代赢、富时收入赢
上升段：替代效应＞收入效应，供给随工资增加；后弯段：收入效应＞替代效应，供给随工资减少。向后弯曲的解释＝工资增加的替代效应与收入效应的相互关系。注意：个人的后弯，整个市场的劳动供给曲线仍向右上方倾斜。
向后弯曲的原因：

工资率较低时，替代效应占上风（工资涨 → 多劳动）；工资高到一定程度后，收入效应 > 替代效应（富了想多休闲）→ 曲线向后弯。经济基础第 5 章与人力第 11 章同源考点。

📈 宏观经济（第6–9章）

消费函数与储蓄函数

消费函数与储蓄函数：互为补数
左：C＝α＋βY 与 45°线交于收支相抵点 B；右：S＝Y−C，在 B′ 处 S＝0
APC＋APS＝1，MPC（β）＋MPS（s）＝1——同平同边才凑 1；B 左侧 C＞Y（入不敷出），右侧 C＜Y（有储蓄）。MPC＜APC：平均里有自发消费 α 垫底。
消费与储蓄：
  • 消费函数 C = α + βY（β = 边际消费倾向 MPC）
  • MPC + MPS = 1；乘数 = 1/(1−MPC)，越敢花钱乘数越大

总需求与总供给（AD-AS）

总供求模型：需求拉动型通货膨胀
短期：AD 右移 → 产量↑、价格↑；长期：AS 垂直，AD 右移只推高价格
短期 AS 向右上（价格影响供给）；长期 AS 垂直——只取决于劳动、资本、技术与经济体制，与价格总水平无关。长期里总供给定产量、总需求定价格。决定总供给的基本因素＝价格和成本。
AD-AS 三段：
  • AD 曲线向右下方倾斜（财富效应、利率效应、出口效应）
  • AS 曲线三段：水平（凯恩斯区域，资源大量闲置）→ 向右上方（常规区域）→ 垂直（长期，充分就业，产出不随价格变）

菲利普斯曲线

菲利普斯曲线：短期有得换，长期一条竖线
最初版：失业率↔货币工资率（菲利普斯）；简单版：通胀率↔失业率
短期：通胀与失业存在替代关系——用高通胀换低失业，或用高失业换低通胀；长期（弗里德曼）：替代关系不存在，曲线垂直于横轴——通胀"骗"不出低失业。版本口诀：最初工资、简单通胀。
菲利普斯：

失业率与通货膨胀率此消彼长（跷跷板）：压失业 → 通胀升；压通胀 → 失业升。

拉弗曲线

拉弗曲线：税率与税收收入
先增后减有拐点——保持适度的宏观税负水平
税率从 0 提高，税收先增加；越过拐点后再提高，税收反而减少——"税率越高、税收越多"必错。政策提示：征税有禁区、注意涵养税源（税源＝国民收入/GDP）；理论来源：供应学派（20 世纪 70 年代，回应凯恩斯主义需求管理失效）。
拉弗：

税率与税收收入倒 U 形：税率过高 → 抑制劳动与投资 → 税收反而减少。

经济周期波动

经济周期：围绕趋势的扩张与收缩
总体经济活动沿增长的总体趋势有规律地波动，由一组经济总量指标共同反映
扩张阶段（复苏→繁荣）：增长持续提高、常伴通货膨胀；收缩（衰退）阶段：增长下滑、失业率提高。类型判断看低谷年增长率：为负＝古典型（总量绝对减少），为正＝增长型（我国改革开放以来属增长型）。
🧠 复苏→繁荣→衰退→萧条

四阶段顺序记"复繁衰萧"；顶峰与谷底是转折点。长（康德拉季耶夫 50–60 年）、中（朱格拉 8–10 年）、短（基钦 3–5 年）。

📈 市场失灵与财政（第6、13章）

外部性

外部性与资源配置失当
私人账本与社会账本错位，市场自己算不出最优产量
外部经济：私人收益＜社会收益 → 产出偏低（Q1＜Q2）；外部不经济：私人成本＜社会成本 → 产出偏高（Q1＞Q2）。口诀：正外低、负外高——拿不全收益就少干，甩不掉成本就多干。
外部性判方向：
  • 负外部性：私人成本 < 社会成本 → 产出高于社会最优 → 征税
  • 正外部性：私人收益 < 社会收益 → 产出低于社会最优 → 补贴

税负转嫁（弹性决定谁买单）

税负归宿：供需弹性决定谁扛税
征税使 S0 上移到 S1（税额 t）：涨价部分买方扛、少收部分卖方扛
需求弹性小（必需品）、供给弹性大 → 买方承担大头，税负容易转嫁；需求弹性大（非必需品）→ 卖方承担大头，税负难转嫁。口诀：求小供大易，必需间接范围宽。
🧠 求小供大易转嫁

需求弹性小（必需品）+ 供给弹性大 → 买方承担大头，税负容易转嫁；反之卖方承担。

📈 统计（第23–27章）

相关关系散点图

散点图：相关方向一眼判
点自左下走向右上＝正相关；左上走向右下＝负相关；杂乱无规律＝不相关
三个维度各管一件事：程度（完全相关／不完全相关／不相关——大部分现象属不完全相关）、方向（正／负）、形式（线性／非线性），三者可自由组合。
相关方向：

散点从左下到右上 = 正相关；左上到右下 = 负相关；一团乱 = 不相关。相关系数 r ∈ [−1, 1]，|r| 越大线性关系越强。

一元线性回归

最小二乘法：让残差的平方和最小
竖直虚线＝每个观测点的残差（观测值 yi − 估计值 ŷi），直线选得让全部残差的平方和最小
使因变量的观测值与估计值之间的离差（误差项 ε）平方和最小。三个偷换陷阱：不是与均值比、不是乘积最小、不是标准差最小。
回归线：

最小二乘法拟合直线；r²（决定系数）越接近 1，拟合越好。

📈 人力资源（第2–3章）

管理方格图

管理方格图：先横后纵（横＝关心任务，纵＝关心人）
布莱克和默顿：两个维度均高（9,9）效果最好
五个特殊坐标：(9,9) 最理想、(1,1) 无为而治、(5,5) 中庸式、(1,9) 乡村俱乐部、(9,1) 任务。口诀：先横后纵——横 9 纵 1 是任务狂，横 1 纵 9 是乡村俱乐部。
🧠 横任务纵人，9.9 最优

横轴关心任务、纵轴关心人；(9,9) 团队型最有效；(1,9) 乡村俱乐部型只顾人；(9,1) 任务型只顾活；(1,1) 贫乏型最差。

矩阵制组织结构

矩阵组织形式：纵向与横向管理系统相结合
职能分工（纵向）＋ 产品／项目分工（横向）＝ 双重指挥的网格结构
特点：一名员工有两位领导、两个层次的协调、横向联系灵活多样；优点：协作配合、适应性、减轻高层负担、相互制约；缺点：稳定性较差、多头指挥责任不清。适用环境：复杂／动态（口诀：矩复动）。
矩阵制：

双重领导（职能 + 项目）；优点：灵活、跨部门协作；缺点：多头领导、权责不清。案例题常考"为什么推诿扯皮"。

事业部制

事业部制：集中决策，分散经营
按产品或地区设事业部，每部都是基本经营单位（斯隆提出）
总部管战略（集中决策），事业部一条龙自己打仗（分散经营、单独核算、自负盈亏）。优点：高层摆脱事务、增强活力、联合化＋专业化；缺点：本位主义、机构重复成本增。适用：产品种类多且工艺差别大、市场广且变化快的大型联合企业。
事业部制：

"集中决策、分散经营"；按产品/地区/客户划分事业部，独立核算。优点：总部战略、事业部灵活；缺点：机构重复、管理成本高。
