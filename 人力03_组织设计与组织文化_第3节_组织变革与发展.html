一、组织变革

1. 组织变革的概念与情形 高频考点

组织变革：组织为了适应内外环境的变化而对其自身进行的调整和修正。

组织变革的情形（西斯克提出，出现以下信号就说明该变了）： 1. 组织决策失灵； 2. 沟通不畅； 3. 组织不能发挥效率； 4. 缺乏创新。

🧠 四个红灯

"策、沟、效、新"四个红灯——决策失灵、沟通不畅、效率不彰、创新缺乏。多选题会拿"组织规模扩大、员工离职"之类日常现象当干扰项，红灯清单里没有的都不选。

例子　

一家公司开会没人敢拍板（决策失灵）、部门之间传话靠猜（沟通不畅）、加班很多但产出不行（效率不彰）、三年没推出像样的新品（缺乏创新）——四个红灯一亮，这家公司该变革了。

2. 组织变革的方法与程序（★★★）★★★ 高频考点

变革方法 具体内容
以人员为中心 提高人的知识和技能，改变人的态度、行为及群体行为等
以结构为中心 重新划分和合并部门，调整管理层次和管理幅度，任免负责人，明确责任和权力等
以技术为中心 工作流程再设计，方法和设备的改变，组织管理体系建立
以系统为中心 变革某一因素时，注意它对其他因素（人员、结构、技术）的影响；考虑组织系统与外部环境之间的平衡

组织变革的程序（四步）：①确定问题 → ②组织诊断 → ③实行变革 → ④变革效果评估。

🧠 上岸熊口诀：四中心

"人技结构系统"——动人不改架构（人员：知识技能、态度行为），改架构不动人（结构：分合部门、调层次幅度、任免负责人、明责权），换家伙什改流程（技术：流程再设计、改设备、建管理体系），动谁都要看全局和外部平衡（系统）。2023 年单选"调整管理层次和管理幅度"就是结构中心的标配动作。

💡 两个固定陷阱

①"以文化为中心"不是教材所列的变革方法，是编外干扰项——四种方法只有人员、结构、技术、系统。②分不清"结构还是技术"时看动作对象：调部门、调层次幅度、任免负责人＝结构；改流程、换设备、建管理体系＝技术。

二、组织发展

3. 组织发展的含义与观念目标（★★★）★★★

组织发展：有计划变革及干预措施的总和，寻求增进组织的有效性和员工的幸福感。它注重人性和民主等因素，排斥控制、冲突、压力等；重视人员和组织的成长、合作与参与过程及质询精神。

组织发展的观念与目标（★★★，5 条）： 1. 对人的尊重； 2. 信任和支持（主张建立新型、有效而健康的组织，形成信任、真诚、开放和支持的氛围）； 3. 权力平等； 4. 正视问题； 5. 鼓励参与。

🧠 观念目标五条

"尊、信、平、正、参"——尊重、信任、平权、正视问题、参与。方向感只有一条：组织发展全部朝"人性、民主"拧，凡"强调等级和权威""靠控制压任务"的说法都反了（2022 年多选就考了这一点）。

例子　

一家企业推行组织发展：让基层员工参与排班规则的制定（鼓励参与、权力平等）、季度复盘会上摆问题不追责（正视问题、信任支持）、管理者一对一倾听而不下命令（对人的尊重）——整个调性是"民主协商"，而不是"管控施压"。

4. 组织发展的方法（★★★）★★★ 高频考点

传统的组织发展方法分两筐：

类别 具体方法 一线分
结构技术 合并职能部门、减少垂直分化度、简化部门规章、扩大员工自主性；工作再设计（使工作更具挑战性、趣味性） 动"架构和岗位"
人文技术 敏感性训练、调查反馈、质量圈、团际发展 动"人和沟通"

四个人文技术的细节（★★★）：

方法 要点
敏感性训练 又称实验室训练、T 团体训练、交友团体训练；通过小组成员之间的交互作用方式来改善行为；团体注重相互作用的过程，而不是讨论的结果；效果：群体凝聚力更强，功能失调的人际冲突减少
调查反馈 了解员工们在认识上的差异的一种调查工具；通常以问卷形式进行，可以针对个人，也可以针对整个部门或组织
质量圈 员工参与计划的形式；要求：①设立明确的项目目标，告知所有相关人员；②最高管理层予以支持；③创造有益于参与管理的组织气氛；④选出称职的项目管理者；⑤项目的所有参与人必须接受质量圈培训
团际发展 又称群体间关系的开发；旨在化解和改变工作团体之间的态度、成见和观念，以改善团体间的相互关系

现代的组织发展方法：

方法 要点
全面质量管理 强调依靠协同工作得到组织中每个人对质量的承诺，是一个在长期经营中不断改进质量的过程。要求：①变革必须植根于企业最根本的部分（组织文化），文化的改变必须在实行全面质量管理之前或与之同时进行；②挑选具有高度责任感的员工；③需要最高管理层的支持；规划从上向下，实施从下向上
团队建设 好团队四特征：①规模小；②能力互补；③有共同的意愿、目标和工作方法；④情愿共同承担责任。工作、业余生活双管齐下效果更好
🧠 上岸熊注释：人文技术怎么分

敏感性训练＝练人与人之间的沟通协作技巧；团际发展＝练团队与团队之间的沟通改善；质量圈类比第 1 章参与管理里的"质量监督小组"（都是员工参与的形式）。再配一句："结构动架构，人文动人心"。

结构技术 vs 人文技术，一线分：

看动作对象：合并部门、减垂直分化度、简规章、扩自主性、工作再设计＝结构技术；敏感性训练、调查反馈、质量圈、团际发展＝人文技术。陷阱在名字上——"实验室训练"听着像设备和技术，其实是敏感性训练的别称，属人文技术。

💡 高频多选＋方向细节

①人文技术是 2024 年两场考试连考的多选——敏感性训练、调查反馈、质量圈、团际发展四个一组记牢，"工作再设计"永远留在结构筐里。②全面质量管理的方向题：文化改变先行或同时（不能滞后）、规划从上向下、实施从下向上——三个方向拧错一个就是错误选项。

📌 本节速记卡
  • 组织变革：适应内外环境变化的调整和修正；四个红灯"策沟效新"（决策失灵、沟通不畅、效率不彰、缺乏创新）
  • 变革四方法："人技结构系统"——人员（知识技能、态度行为）、结构（分合部门、调层次幅度、任免负责人、明责权）、技术（流程再设计、改方法设备、建管理体系）、系统（顾其他因素＋外部平衡）；程序四步：定问题→组织诊断→实行变革→变革效果评估
  • 组织发展：有计划变革及干预措施的总和，增进组织的有效性和员工的幸福感；重人性民主、排斥控制冲突压力；观念目标"尊信平正参"
  • 传统方法：结构技术（合并部门、减垂直分化度、简规章、扩自主性、工作再设计）/人文技术（敏感性训练、调查反馈、质量圈、团际发展）
  • 敏感性训练：又名实验室训练、T 团体训练、交友团体训练；重过程不重结果；凝聚力更强、人际冲突减少
  • 现代方法：全面质量管理（文化先行或同时、高度责任感员工、高层支持、规划从上向下实施从下向上）；团队建设（小、补、同、担，工作业余双管齐下）
