☁️ 云同步（跨设备）

绑定一个私有仓库后，答题进度自动在所有设备间同步（每台设备配置一次，之后免操作）。配置保存在本设备的浏览器中，令牌仅授权这一个仓库。
如何创建 Gitee 私有仓库和私人令牌？（约 2 分钟，一次即可）
  1. 打开 gitee.com 注册/登录（手机号即可，国内直连）。
  2. 右上角 + → 新建仓库 → 名称填 jingjishi-progress → 勾选私有 → 勾选"使用 Readme 文件初始化" → 创建。
  3. 头像 → 设置 → 安全设置 → 私人令牌 → 生成新令牌 → 勾选 projects → 提交 → 立即复制令牌（只显示这一次）。
  4. 回到本页，仓库填 你的用户名/jingjishi-progress，粘贴令牌，点"保存并连接"。
如何创建 GitHub 私有仓库和 token？（需能访问 GitHub）
  1. 登录 GitHub → 右上角 + → New repository → 名称填 jingjishi-progress，选 Private，勾选 Add a README → Create。
  2. GitHub → 头像 → Settings → 最底部 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  3. Repository access 选 Only select repositories 并选中 jingjishi-progress；Permissions 里 Repository permissions → Contents 设为 Read and write → 生成并复制 token。
  4. 回到本页，粘贴仓库名与 token，点"保存并连接"。

已绑定仓库：　上次同步：

换新设备/新浏览器：打开本页 → 选择同样的后端，填同一个仓库名和令牌 → 首次同步会自动把云端进度合并下来。
